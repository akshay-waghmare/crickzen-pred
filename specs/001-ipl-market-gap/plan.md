# Implementation Plan: IPL Model Improvement — Close Market Gap

**Branch**: `001-ipl-market-gap` | **Date**: 2025-07-16 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/001-ipl-market-gap/spec.md`

## Summary

Close a ~28% Brier score gap (model 0.1977 → market 0.1546) between the IPL cricket prediction model and the betting market through 6 prioritized improvements: (1) IPL-specific wicket penalty tables derived from 273K training rows, (2) empirical final-over lookup replacing the sigmoid approximation, (3) recency-weighted team ratings with RCB deduplication, (4) updated first-innings scoring midpoint from 165→173, (5) phase-wise Platt scaling calibration (6 calibrators), and (6) market-as-feature ensemble blending. All changes are configuration/feature-level — the core XGBoost+LogReg model architecture remains frozen.

## Technical Context

**Language/Version**: Python 3.10+ (pyproject.toml requires ≥3.10)  
**Primary Dependencies**: XGBoost ≥2.0, scikit-learn ≥1.3, pandas ≥2.0, NumPy, structlog, Pandera, joblib  
**Storage**: Parquet files (feature store: `data/ipl_feature_store_v1/`, training: `data/ipl_features_v1/training.parquet`)  
**Testing**: pytest (tests/unit/, tests/integration/, tests/telegram/)  
**Target Platform**: Windows (development), Docker (production)  
**Project Type**: Single Python package (`bbl_pipeline`) with CLI entry point  
**Performance Goals**: Overall model Brier ≤ 0.170 (from 0.1977), closing 60–70% of gap to market's 0.1546  
**Constraints**: No regression on any segment (Pareto-improving); ECE < 0.0021 per constitution; calibration on held-out set only  
**Scale/Scope**: 273,503 training rows, 510 validation observations, 16 IPL matches, ~30 model features
